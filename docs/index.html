00

Lock Rev A

A buildable target, not a shrinking wish-list.

  • 52 positions, forward rotation only
  • Proven 54 × 43 × 0.762 mm CR80 flap halves
  • Approx. 60 mm drum; expect 125–145 mm module height
  • One MCU, driver, Hall sensor and RS-485 transceiver per character

PASS GATE: Do not customise dimensions until a proven mechanism moves.

01

Print fit coupons

Your printer tells us the real tolerances.

  • Test flap pivot slots at nominal, +0.1, +0.2 and +0.3 mm
  • Test the motor shaft socket and M3 free-side axle
  • Test magnet pockets before inserting a magnet
  • Write the winning dimensions on the parts

PASS GATE: Every fit is firm but movable; nothing needs forcing.

02

Make a 3–5 flap gravity rig

Prove the hardest mechanical action before spending more.

  • Cut CR80 cards in half with a printed jig
  • Punch identical pivot tabs/notches
  • Mount only 3–5 flaps and turn by hand
  • Adjust the pawl/backstop until every flap falls cleanly

PASS GATE: 100 hand-turned cycles with zero jams.

03

Build a 10–12 position powered drum

Cheaply test motor, noise, speed and homing.

  • Plug the 28BYJ-48 into its ULN2003 board
  • Connect a pre-headered ESP32-C3 using female leads
  • Connect a pre-built Hall board and one rotor magnet
  • Measure motor winding resistance and actual steps per revolution

PASS GATE: 100 powered cycles; home is found at the same point every time.

04

Build character module 01

One complete 52-position character.

  • Cut and label all 52 flap halves
  • Install the M3 free-side axle, drum and adjustable pawl
  • Add the 3.3 V MAX3485 RS-485 module
  • Save module ID 01 in MCU flash

PASS GATE: 1,000 cycles with no jam, stall or missed-home event.

05

Duplicate module 02

Two truly independent modules.

  • Build from the same files and recorded tolerances
  • Save ID 02
  • Join A/B/GND/power on a short linear bus
  • Terminate only the two physical ends of the RS-485 trunk

PASS GATE: Send different targets to IDs 01 and 02 for 500 mixed moves.

06

Build the Pi controller

The brain sends commands; it never drives a motor.

  • Install Raspberry Pi OS Lite on microSD
  • Plug in a USB-to-RS-485 adapter—no GPIO header required
  • Run the controller service and discover IDs 01 and 02
  • Send target positions and read status/fault replies

PASS GATE: Unplug the Pi: both visible characters stay where they are.

07

Test snap-together edges

Only now validate the modular promise.

  • Print alignment peg/socket coupons
  • Use magnets for holding, geometry for alignment
  • Prototype spring pogo pins against large ENIG pads
  • Cycle the joint 250 times while checking voltage and packets

PASS GATE: No intermittent power/data and no sliding under module weight.

What each module owns

  • Unique ID in MCU flash
  • 52-entry character map
  • Motor sequencing and measured step count
  • Hall home and fault recovery
  • Current position while powered

What the Pi owns

  • Layout: ID → row/column
  • Text, clock, animations and web UI
  • Discovery and status polling
  • Scheduling and integrations
  • Never direct motor GPIO

Critical bus correction

RS-485 wants a linear trunk with short stubs and 120 Ω at its two ends. Four identical edge contacts are mechanically attractive, but arbitrary 2D branches and loops are not automatically reliable. Prove two modules first; later add configurable routing or active repeaters.

NO-SOLDER WIRING RULES

Plug, clamp, screw. Nothing else.

01

Buy fitted connectors

Loose headers in a bag fail your rule. Photos are not enough—ask the seller to confirm they arrive soldered.

02

Separate prototype from product

Dupont leads are fine on the bench. Production modules need factory-assembled locking connectors and strain relief.

03

Common ground

Logic and RS-485 need a shared reference. Keep motor current out of thin signal leads.

04

Power off before moving wires

Never rewire while powered. Fuse the shared supply and cover exposed terminals.

Never laser-cut PVC or unknown plastic. PVC can release toxic, corrosive gases. Use a guillotine, punch, drag knife or professional die cutting after checking the material data sheet.
