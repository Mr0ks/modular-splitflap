0 of 9 stages passed

GOAL · Confirm the project is ready for a cheap experiment.

Before you buy anything

  1. Create a free GitHub account and install OpenSCAD plus Arduino IDE.
  2. Print a 20 mm calibration cube; measure it with your calipers or ruler.
  3. Check that your printer can make a clean 0.2 mm layer and 0.4 mm nozzle print.
  4. Read the shopping-list rules below. Never order a board with loose headers.
  5. Set aside AU$30 for this first 12-flap test—not for the finished two-module system.

PASS BEFORE CONTINUINGYou know your printer works and every electronic listing is genuinely plug-in.

GOAL · Spend the minimum needed to find out whether the mechanism can work.

Buy only the starter test parts

  1. Buy the eight lines marked BUY NOW.
  2. Do not buy the Raspberry Pi yet.
  3. Do not buy pogo pins, 100+ magnets, a custom PCB or die-cut tooling.
  4. Combine suppliers where delivery costs more than the part.
  5. Save screenshots of the exact motor voltage and connector photos.

PASS BEFORE CONTINUINGAll parts arrive with fitted connectors; nothing requires soldering.

GOAL · Make the motor turn and the Hall sensor detect a magnet before printing a full module.

Test the electronics on the table

  1. Plug the motor into the ULN2003 socket.
  2. Use four jumper wires from ESP32 GPIO pins to IN1–IN4.
  3. Connect ULN2003 GND and ESP32 GND.
  4. Connect the Hall module to 3.3 V, GND and one input pin.
  5. Upload a basic forward-step test; move the magnet past the sensor and watch the serial output.

PASS BEFORE CONTINUINGMotor completes 100 forward revolutions and HOME is detected every time.

GOAL · Learn your real tolerances without wasting a large print.

Print the tiny mechanical tests

  1. Print four flap-slot samples: nominal, +0.1, +0.2 and +0.3 mm.
  2. Print the motor-shaft socket, M3 axle hole and magnet pocket as separate coupons.
  3. Choose the loosest flap slot with no sideways wobble.
  4. Write the winning clearance values down.
  5. Never force a magnet into a pocket; adjust and reprint.

PASS BEFORE CONTINUINGFlaps swing freely, axle rotates, motor socket grips and magnet seats safely.

GOAL · Prove gravity, drum and pawl geometry cheaply.

Build the 12-flap mechanism

  1. Cut six CR80 cards exactly in half to make 12 flap halves.
  2. Punch identical pivot tabs using a printed jig.
  3. Print a 12-position test drum and side frame using your measured clearances.
  4. Fit the M3 free-side axle and adjustable pawl.
  5. Turn by hand for 100 cycles, then connect the motor for 500 cycles.

PASS BEFORE CONTINUINGZero jams, flaps fall cleanly and the pawl holds the displayed face.

GOAL · Scale the proven mechanism to all 52 positions.

Only now build module 01

  1. Use 52 flap halves: 26 CR80 cards.
  2. Keep the proven 54×43×0.762 mm flap-half geometry for Rev A.
  3. Use a roughly 60 mm drum and forward-only rotation.
  4. Install the motor, Hall sensor, magnet and ESP32-C3.
  5. Measure actual steps per revolution; do not assume the internet value is correct.
  6. Assign and save module ID 01.

PASS BEFORE CONTINUINGModule 01 completes 1,000 mixed character moves without a jam or home error.

GOAL · Prove that modules are replaceable building blocks.

Build the identical second module

  1. Print the same files with the same settings.
  2. Install the same parts and assign ID 02.
  3. Test module 02 alone for 1,000 moves.
  4. Buy and connect one 3.3 V MAX3485 board per module.
  5. Wire A-to-A, B-to-B and GND-to-GND as a short straight bus.

PASS BEFORE CONTINUINGOne computer command can send module 01 and module 02 to different positions.

GOAL · Replace the test computer with the permanent brain.

Build the Raspberry Pi controller

  1. Buy a Raspberry Pi Zero W, a 16 GB or larger microSD and a proper power supply.
  2. Write Raspberry Pi OS Lite to the microSD—this is why the Pi needs storage.
  3. Plug a USB-to-RS-485 adapter into the Pi using an OTG adapter.
  4. Connect adapter A/B/GND to the same straight bus.
  5. Run controller software that sends address + target position and reads status.

PASS BEFORE CONTINUINGThe Pi independently commands IDs 01 and 02; unplugging it leaves both letters visible.

GOAL · Validate the snap-together interface without hiding mechanical faults.

Test module-to-module connectors last

  1. Print alignment pegs/sockets first; magnets provide holding force only.
  2. Prototype large contact pads and spring pogo pins on one joining edge.
  3. Route RS-485 as a linear trunk; do not create arbitrary branches or loops yet.
  4. Join and separate the modules 250 times.
  5. Measure voltage during simultaneous movement and count packet errors.

PASS BEFORE CONTINUINGNo sliding, resets, brownouts or dropped commands across 250 connection cycles.

RULE

WHO CONTROLS WHAT

Every character has its own chip.

RASPBERRY PI“Module 02, go to position 41.”

Stores layout, text, clocks and the web interface.

RS-485 BUSAddress + command + checksum

Carries messages; does not drive motors.

MODULE 02 MCUHomes, counts and drives itself.

Own ID, motor, sensor and local fault handling.

Three rules that do not change

1. No soldering means fitted headers, plug-in motor sockets, screw terminals and later factory-assembled PCBs.

2. Move forward only. Reversing a split-flap drum can lift or jam flaps.

3. Never laser-cut PVC. Cut cards mechanically with a jig, guillotine or punch.
