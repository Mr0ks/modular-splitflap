# Modular Splitflap

A researched, beginner-readable roadmap for building two no-solder, independently addressed split-flap character modules and a Raspberry Pi controller.

The live guide includes:

- an evidence-backed Rev-A specification;
- an interactive, locally saved build checklist;
- current Australian and overseas supplier comparisons in AUD;
- a downloadable BOM and 52-position character map;
- Raspberry Pi / per-module MCU / RS-485 architecture;
- mechanical test gates, safety guidance and manufacturing options.

## Important status

This repository currently contains the research and build-planning website. It does **not** yet claim to contain physically validated custom CAD, PCB or firmware. Those files should be released only after the documented fit, motion, homing and two-module bus tests pass.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
